PROJECT PHOTO GALLERY

Put project photos inside the respective project folder.

Supported image formats:
PNG, JPG, JPEG, WEBP

Example:
assets/projects/data-center/data-center-01.png
assets/projects/data-center/data-center-02.png
assets/projects/data-center/data-center-03.png
assets/projects/data-center/data-center-04.png

You do NOT need to rename PNG files to JPG.
The website automatically checks .png, .jpg, .jpeg and .webp.

After adding images, refresh the website with Ctrl + F5.
